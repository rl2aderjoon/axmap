# 벤치 원본 기록 — 고치지 않는다

여기 있는 것은 **페르소나 벤치를 실제로 돌린 날의 원문**이다.
각 회차 폴더에 지시문(`persona-*.md`)과 그 답변(`answers-*.md`), 그리고
실행 조건(`run.json`)이 들어 있다.

| 회차 | 대상 저장소 | 조건 |
|---|---|---|
| `20260820T011901Z-alluxio` | alluxio | text · viz · both |
| `20260820T020721Z-Parsley.js` | Parsley.js | text · viz · vizonly · both |
| `20260820T0630Z-ziti-formats` | ziti | text · graph · ladder · reveal · watch |

## 🔴 이 폴더에는 옛 이름이 남아 있다

이 저장소의 규칙은 *"팀 저장소에 옛 이름을 다시 들이지 않는다"*
([docs/HANDOVER.md](../../../docs/HANDOVER.md) 5절)인데, **이 폴더만 예외다.**

이유는 하나다. 이 파일들은 **측정 원문**이다. 페르소나에게 실제로 준 지시가
`· blastmap 자신의 코드를 읽지 마라` 였고, 그가 실제로 낸 답이
`blastmap이 정적으로 찾아낸 진입점 후보(총 863개) 중…` 이었다.

이름을 바꾸면 **주지 않은 지시를 준 것으로, 하지 않은 말을 한 것으로** 만든다.
그건 기록이 아니라 재구성이다. 그리고 이 저장소는 이미 같은 모양의 실패를
경고해 뒀다 — [CLUSTER.md](../CLUSTER.md) 의 *"유리한 쪽으로 자를 갈아끼우는 것"*.

**그래서 한 글자도 안 고쳤다.** 도구 이름이 바뀐 것은 2026-08-25 이고,
이 기록들은 그 닷새 전인 2026-08-20 의 것이다. 읽을 때 그 시차를 감안한다.

## 이 기록이 무엇을 증명하고 무엇을 증명하지 않나

**증명한다** — 그날 그 조건으로 그 답이 나왔다는 것. 지시문이 함께 있으므로
답이 조건에서 나온 것인지, 페르소나가 조건 밖을 봤는지 대조할 수 있다.

**증명하지 않는다** — 지금 화면도 같은 답을 낸다는 것. 커밋 `141e684` 가
그때의 화면을 지웠다. `tools/persona-bench.mjs` 가 아직 `?step=` `?unit=`
`?watch=` 를 겨누는데 지금 화면이 읽는 것은 `?agent=` 하나뿐이라, **그대로
돌리면 온보딩 화면만 열 장 찍힌다.**

다시 재려면 하네스를 먼저 지금 화면에 겨눠야 한다 — [BENCH.md](../BENCH.md)
의 "다시 여는 법" 절과 [S15P21E201-4](https://ssafy.atlassian.net/browse/S15P21E201-4).
