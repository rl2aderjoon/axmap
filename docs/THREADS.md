# 진행 중인 작업

## 협업 메시지의 우선순위와 묶음 처리

S15P31E109-207 후속: 일반 메시지의 무호출 저장·작업 경계 회수, 긴급 사유 분류와
명시적 단일 묶음 전송을 구현한다. [SESSION-MAILBOX.md](SESSION-MAILBOX.md)를 따른다.
실제 에이전트 작업 루프의 회수 적용, 실행 중 provider의 긴급 알림/interrupt 확장과
실사용 턴 절감 측정은 별도 검증이 필요하다. 기존 단일 실행·자동 대화는 유지한다.

현재 범위는 [DECISIONS.md](DECISIONS.md)를 따른다.

## 열린 AI 세션 연결

관리형 Codex App Server와 agy stream-json의 실제 자동 왕복 및 MCP 백그라운드 접수를 검증했다.
각 프로세스와 대화 맥락을 유지하며 요청별·누적 사용량을 추적한다. 별도 PTY 연결은
가짜 대화형 provider의 회귀 검증 단계이며 실제 TUI 연결 성공으로 소개하지 않는다.
세부 상태는 [SESSION-BRIDGE.md](SESSION-BRIDGE.md)에 둔다.

다음으로 확인할 항목:

- 모델·CLI 버전별 관리형 연결 호환성과 기본 문맥의 토큰 비용을 관찰한다.
- 종료 훅이 이전 사용자 입력의 응답을 이번 작업의 결과로 오인하지 않도록 한다.
- 작업 종료 직후 사용자가 입력한 내용을 지연 타이머가 지우지 않도록 한다.
- 중단·종료·권한 대기·동시 입력과 연결 단절을 검증한다.

## 설치부터 사용까지

- 깨끗한 환경에서 npm 패키지 설치와 setup의 실행 사본을 검증한다.
- 플랫폼별 prebuilt 의존성과 경로에 공백이 있는 환경을 확인한다.
- 사용자가 연결 주소를 복사하거나 별도 빌드 도구를 설치하지 않는 시작 흐름을 다듬는다.
