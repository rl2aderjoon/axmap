# UI 아이디어 — 재보는 중인 것들

화면에 대해 떠오른 것을 **한 줄로** 쌓는 곳. 아직 아무것도 확정이 아니다.

## 쓰는 법

- 번호는 `U<숫자>`. **주소이므로 재배치하지 않는다** — 끝난 것도 지우지 말고 상태만 바꾼다
  (`docs/THREADS.md` 의 실 문자와 같은 규칙이다).
- 한 줄에 담기지 않으면 **그건 아이디어가 아니라 조사**다. `YYYY-MM-DD-<대상>.md` 로 뺀다.
- **근거 칸을 비워 두지 않는다.** 근거가 없으면 그건 취향이고, 취향은 여기 쌓지 않는다.
- 만들기로 정해지면 `docs/DECISIONS.md` 로 옮겨 D 번호를 받는다. 여기서는 상태만 ✅ 로 바꾼다.

판정 질문은 언제나 하나다 — **`docs/BENCH.md` 의 M3(핵심까지 몇 번 눌렀나)를 앞당기는가.**
앞당기지 않으면 올리지 않는다 (`app/web/shell.js` 머리말).

### 먼저 풀어야 풀리는 것

🔴 **U1 · U2 앞에 어휘 충돌이 하나 있다.** `app/web/shell.js` 의 `S.agent` 는
"어느 AI CLI 를 쓰나"(claude · agy · codex)를 뜻하는데, U1 이 레일에 올릴 것은
"지금 뭔가 하고 있는 작업 하나"다. **같은 낱말에 뜻이 두 개가 되면**
`docs/WORDS.md` 원칙 C 가 막으려던 상황이 우리 코드 안에서 벌어진다.
레일을 그리기 전에 낱말부터 갈라놓는다.

🔴 **U2 는 claim 만으로는 못 그린다.** `--intent` 는 claim 시점에 한 번 고정되고
TTL 은 30분짜리 거친 입자다. "지금 무엇을 하는 중"을 내려면
**claim 을 갱신형으로 만들지, `app/lib/session.mjs` 에서 따로 끌어올지**
정해야 한다 — 아직 안 정했다.
