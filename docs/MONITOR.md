# 실행 중인 파이프라인 보기

별도 터미널에서 작업 저장소로 이동해 실행한다.

```powershell
axmap monitor
```

열린 세션, 요청의 전달 단계, 자동 대화의 실행 횟수와 확인된 처리 토큰, 현재 작업 선점,
최근 요청·완료·상태 변화를 한 화면에서 갱신한다. 다른 터미널과 AI 도구에서 평소처럼
axMap을 사용하면 같은 저장소의 기록이 나타난다. 기존 agy 창도 `bridge attach`로
연결돼 있으면 표시된다.

```text
axMap LIVE · 진행 확인 1개
── 에이전트 ───────────────────────────────────────────
○ AGY 74eec277 대기 · 연결됨 · 토큰 미측정
── 요청 파이프라인 ─────────────────────────────────────
codex → agy 74eec277 · 응답 대기 · 3초
  ● 접수 ── ● 전달 ── ◐ 응답 대기 ── ○ 완료 확인
  작업  변경 사항을 검토하고 결과를 알려 주세요.
── 최근 이벤트 ────────────────────────────────────────
10:30:01  요청 접수 · codex → 74eec277
```

위 화면은 배치를 설명하는 예다. 실제 화면은 로컬 기록과 연결 확인 결과만 사용한다.
확정되지 않은 전송은 `전달 확인 필요`, 다른 입력이 이어진 요청은 `다른 입력으로 대체됨`,
실패는 사유와 함께 표시한다. 접수됐다는 이유만으로 작업을 완료로 표시하지 않는다.
독립 agy 콘솔은 상세 도구 실행 상태와 사용량을 제공하지 않을 수 있어 `상태 미확인`과
`토큰 미측정`을 그대로 보여준다. 선점은 해당 경로의 소유 기록이며 프로세스 생존 증명이 아니다.

## 조작과 옵션

- `q`, `Esc`, `Ctrl+C`: 모니터를 닫고 원래 터미널 화면과 커서를 복원한다.
  이미 전달한 작업과 모델 프로세스는 계속 실행된다.
- `--cwd <repo>`: 볼 저장소를 지정한다. 기본은 현재 작업 폴더다.
- `--interval 1000`: 상태를 수집한 다음 다음 조회까지 기다릴 시간(ms). 250~60000을 지원한다.
  화면의 대기 표시는 별도로 애니메이션하며 추가 상태 조회를 만들지 않는다.
- `--once`: 현재 상태만 출력한다.
- `--json`: 같은 저장소의 상태를 JSON으로 한 번 출력한다.
- `--no-color` 또는 `NO_COLOR`: 색상을 끈다. 터미널 크기가 작으면 요약 화면으로 바뀐다.

```powershell
axmap monitor --cwd C:\work\my-repo
axmap monitor --once
axmap monitor --json
```

출력을 파일이나 파이프로 보내거나 `TERM=dumb`인 터미널에서는 한 번만 출력한다.
폰트는 현재 터미널 프로필 설정을 따른다. Pretendard를 사용하려면 터미널 프로필의
글꼴로 선택한다. 프로그램은 프로필이나 전역 글꼴 설정을 변경하지 않는다.

## 관측 범위와 비용

모니터는 모델에 요청하지 않고 작업을 재전송하거나 승인하지 않는다. Git 원격 조회,
장부 생성이나 쪽지 읽음 처리도 수행하지 않는다. 로컬 상태 확인과 기존 요청의 결과
조회만 수행하며, 확인한 완료 결과는 기존 요청 기록에 반영될 수 있다.

한 번의 갱신에서 수신 세션당 하나, 최대 네 개의 미확정 요청을 확인한다. 연결 확인에
걸리는 시간이 갱신 간격에 더해질 수 있다. 화면 애니메이션은 수집 간격과 분리돼 있다.
요청·대화 기록은 종류별 최근 500개를 읽고 현재 저장소만 골라 표시한다. 화면 데이터는
최근 요청 50개, 대화 20개, 이벤트 40개까지 보관한다. 기록이 잘렸거나 읽기에 실패하면
경고를 표시한다. 이벤트는 저장된 요청 시각과 모니터가 관측한 상태 변화이며 전체 도구
실행 내역을 복원하는 감사 로그는 아니다.

인증 토큰이 포함된 원본 세션 파일을 그대로 출력하지 않으며,
`--json`의 요청 데이터에는 사용자가 보낸 작업 본문과 결과가 포함될 수 있다.
터미널에 표시하는 외부 문자열은 제어 문자를 제거하고 화면 너비에 맞춰 자른다.

개발 원본은 `src/monitor.mts`, `src/monitor-cli.mts`다. 변경 후 `npm run build`로 실행
파일을 갱신한다. 모니터의 화면 종료는 별도 실행 중인 CLI를 종료하는 동작과 구분한다.
