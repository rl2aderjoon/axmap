# 공개 저장소 분리 기록

2026-10-13에 `https://lab.ssafy.com/rleaderjoon/axmap.git`의 `team-sync` 커밋 `128dcc1ff02cd99c687314d7f066ea2283ec86a8`에서 axMap 관련 파일을 분리했다.

CLI·MCP·웹 지도·데스크톱 셸·코퍼스·거버넌스·테스트와 제품 규격·설계·벤치 기록을 포함한다. 가볼래 서비스의 프론트 배포본, 여행 서비스 설계·데이터·설문·City3D·발표·인수인계와 개인 운영 절차는 포함하지 않는다. axMap 설계 근거에 해당하는 과거 측정 사례는 남겼다.

기본 브랜치는 `main`이다. 공개 저장소는 정리된 소스의 새 시작 커밋에서 출발하며, 이전의 혼합 이력·작업 장부·쪽지·사용자 상태 브랜치와 과거 태그는 옮기지 않았다. 원본 GitLab 저장소와 기존 로컬 저장소에는 이전 이력이 남아 있다.

패키지 저장소·홈페이지·이슈 주소와 설치 안내를 GitHub로 바꿨다. 반환된 외부 기준 서버 대신 로컬 코퍼스 서버를 기본으로 사용하며 `AXMAP_SSOT_URL` 설정은 계속 지원한다. npm의 기존 `1.2.5` 배포 내용은 변경하지 않았다.
