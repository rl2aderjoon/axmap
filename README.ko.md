# axMap

**한 저장소에서 일하는 여러 AI가 서로의 작업을 덮어쓰지 않도록.**

axMap은 수정할 파일과 폴더를 미리 선점하고, 겹치는 작업을 알려주는 협업 CLI입니다.
Codex·Antigravity·Claude Code에서는 MCP로 선점과 반납, 상태 확인, 쪽지 기능을 사용할 수 있습니다.

[English](README.md) · **한국어** &nbsp; / &nbsp; Node.js 20+ · Git · MIT

## 설치

```bash
npm install -g axmap-cli@latest
axmap setup
```

어느 폴더에서든 한 번 설정한 뒤 AI 도구를 다시 시작하세요.
새 Git 저장소의 장부는 첫 사용 때 자동으로 준비합니다. 함께 일하는 사람은 같은 원격 장부를 사용합니다.

[사용법](docs/INSTALL.md) · [MCP 연결](mcp/README.md) · [개발 가이드](docs/ONBOARD-TEAM.md)

세션·메시지 핵심 모듈은 strict TypeScript로 작성합니다. 단계적 전환 범위와 빌드 방법은 [TypeScript 개발 안내](docs/TYPESCRIPT.md)를 참고하세요.

지원되는 MCP Apps 호스트에서는 대화 안에서 파이프라인을 확인하고, Claude Code·agy에서는 기존 상태줄에 진행을 추가할 수 있습니다. 호스트별 지원이 다르며 ChatGPT·Claude 앱의 실제 임베디드 화면은 아직 검증하지 않았습니다. [클라이언트 설정과 제한](docs/PIPELINE-CLIENTS.md). 선택적으로 별도 터미널의 `axmap monitor`도 제공합니다([사용법](docs/MONITOR.md)).

터미널에서 `axmap view --cwd <저장소>`를 실행하면 관측된 로컬 세션·선점·대기 메시지·최근 이벤트를 카드로 볼 수 있습니다. 화면은 자동 갱신되며 `q` 또는 Esc로 닫습니다. `--once`는 한 번만 출력하고 `--json`은 구조화된 결과를 제공합니다. 등록되지 않은 모든 에이전트나 GitLab 활동까지 표시하는 것은 아닙니다. [화면 사용법](docs/VIEW.md).

## 변경 기록

최신 변경부터 정리합니다.

### 1.7.0

<sub>2026.10.27</sub>

**일반 협업 알림을 작업 경계에서 모아 처리하고 기존 로컬 Codex 대화를 연결합니다.**

- 일반 알림은 `ax_message` / `axmap bridge message`로 새 모델 턴 없이 저장합니다. 수신자는 작업·테스트·실험의 안전한 경계에서 `ax_mailbox`로 묶음 회수합니다.
- 중단 요청·데이터 손상 위험·현재 작업 무효화를 명시적 긴급 사유로 구분합니다. 수신자가 작업 중이면 전달을 보류하며 실행 중 작업을 강제 중단하지 않습니다.
- 발신자·시각·이력을 보존하고 만료, 멱등 키, 같은 발신자·주제의 대기 업데이트 최신화를 지원합니다. 전달불명 메시지는 자동 재전송하지 않습니다.
- 로컬 제어 소켓으로 기존 Codex 대화를 연결합니다. 작업 중에는 관측만 허용하고 새 요청 전 대기 상태를 확인합니다.
- `axmap pipeline` 그래프와 읽기 전용 loopback 웹 화면, 새 모델 턴을 시작하지 않는 Codex 문맥 안내를 추가합니다.

받은 편지함은 격리 provider와 CLI/MCP 계약으로 검증했습니다. 실제 턴 절감량은 미측정이며 실행 중 강제 중단은 지원하지 않습니다. 수신 에이전트가 작업 경계에서 받은 편지함을 회수해야 합니다. 새 도구를 발견하려면 MCP를 다시 연결하세요. 실행용 기존 `ax_dispatch`는 유지합니다.
[받은 편지함 안내 →](docs/SESSION-MAILBOX.md) · [로컬 파이프라인 →](docs/LOCAL-PIPELINE.md)

### 1.6.0

<sub>2026.10.26</sub>

**요청 흐름을 표시하고 기존 Windows agy 연결의 관측 비용을 줄입니다.**

- Windows 콘솔 도우미를 매번 컴파일하지 않고 캐시하며 PowerShell 대체 경로를 유지합니다.
- 제한 시간 안에서 응답을 기다리는 `wait_ms`·`--wait-ms`와 비동기 MCP 진행 알림을 추가합니다.
- MCP Apps 파이프라인 리소스, 텍스트 대체 출력, 기존 명령을 보존하는 Claude Code·agy 상태줄을 제공합니다. 별도 터미널 표시가 필요하면 `axmap monitor`를 사용합니다.
- 세션·파이프라인 모듈을 strict TypeScript로 작성하며 Node.js 20+용 JavaScript를 함께 배포합니다. 실행에 TypeScript 설치는 필요하지 않습니다.

Windows의 실제 agy에서 전달·진행 알림·상태줄의 완료 표시를 확인했습니다. ChatGPT·Claude UI는 기능 협상과 프로토콜 테스트로 검증했으며 실제 제품의 임베디드 화면 검증은 남아 있습니다. 이 Codex 세션에는 새 파이프라인 도구가 노출되지 않았습니다. 로컬 stdio 지원만으로 ChatGPT 웹용 원격 엔드포인트가 생기지는 않습니다.
[클라이언트 설정과 제한 →](docs/PIPELINE-CLIENTS.md)

### 1.5.0

<sub>2026.10.21</sub>

**Windows에서 따로 실행한 Antigravity 대화창을 재시작 없이 연결합니다.**

- 일반 `agy`로 직접 연 대화창도 설치된 훅으로 자동 등록합니다. 이미 열린 창은 대상 저장소에서 `axmap bridge attach --pid <PID>`로 연결합니다.
- `ax_dispatch`와 `ax_result`가 기존 프로세스와 대화를 유지합니다. 빈 입력창의 대기 상태를 확인해 전달하고, 요청 UUID가 있는 대화 기록과 현재 콘솔 상태로 결과를 판정합니다.
- `axmap bridge status [--json]`으로 모델 작업을 보내지 않고 로컬 연결 상태를 확인합니다.
- 독립 콘솔 연결은 현재 Windows agy만 지원합니다. 토큰 예산을 검사하는 `ax_chat`은 관리형 stdio 세션을 사용합니다.

실제 기존 agy 창의 메시지 왕복과 회귀 테스트 574개 통과를 확인했습니다. 독립 콘솔의 자동 등록, 한글 전달, 입력 보호와 프로세스 식별 검사도 포함합니다.
[연결 안내 →](docs/SESSION-BRIDGE.md)

### 1.4.0

<sub>2026.10.20</sub>

**Codex와 Antigravity가 제한된 자동 대화를 주고받으며 토큰 사용량을 추적합니다.**

**추가**

- `axmap bridge serve codex|agy`로 관리형 CLI를 한 번 시작하고, `bridge chat`으로 완료 또는 한도까지 짧은 메시지를 자동 중계합니다.
- MCP `ax_chat`, `ax_dialogue`, `ax_chat_stop`으로 중계 시작·조회·중단을 제공합니다. 요청별·누적 토큰과 캐시 사용량을 기록하며 대기 중에는 모델을 호출하지 않습니다.
- 별도 `axmap run`은 사용자가 직접 여는 대화형 터미널을 연결하는 프로토타입입니다.
- 터미널 연결 의존성을 npm 설치에 포함하고, setup의 실행 사본에도 함께 준비합니다.

**정리**

- 코드 시각화 화면, Electron 앱, 코드 분석·코퍼스 도구와 관련 테스트·연구 문서를 제거했습니다.
- 설치와 MCP에서 쓰는 CLI 탐지 코드를 공용 모듈로 분리했습니다.

**검증 상태**

Windows에서 실제 Codex 0.163.0·agy 1.4.2의 문맥을 유지한 4회 자동 중계와 MCP를 통한 2회 백그라운드 중계를 확인했습니다.
검증 합계는 처리 102590토큰(캐시 입력 54400, 출력 393 포함)입니다. 짧은 메시지도 CLI의 기본 문맥 비용이 크며, 예산은 다음 실행 전에 검사하므로 실행 중 엄격한 토큰 상한은 아닙니다.
별도 대화형 PTY 경로는 가짜 프로그램 회귀 검증 단계입니다.
[개발 상태 보기 →](docs/SESSION-BRIDGE.md)

### 1.3.2

<sub>2026.10.16</sub>

**쪽지에 표시할 이름을 정하고, 동료를 자동으로 찾습니다.**

**추가**

- 대화형 setup에서 표시 이름을 입력합니다. `axmap setup --name "이름"`으로 바꿀 수도 있습니다.
- 저장소를 처음 사용할 때 Git 이메일과 표시 이름을 팀의 사용자 장부에 공유합니다.
- `axmap bus contacts`로 쪽지를 받을 사람을 확인합니다.

**개선**

- 이름으로 보낸 쪽지는 확인된 이메일로 저장해, 이름을 바꿔도 수신·읽음 기록이 이어집니다.
- 동명이인은 이메일로 구분하며, 공유 실패는 경고하고 다음 사용 때 재시도합니다.
- Git 이름·이메일 설정과 투표 권한은 변경하지 않습니다.

### 1.3.0

<sub>2026.10.15</sub>

**저장소를 옮겨도, 세션의 작업 위치를 따라갑니다.**

**추가**

- 첫 상태 조회·선점 때 장부를 자동으로 준비해 저장소마다 `init`을 반복하지 않아도 됩니다.
- MCP가 클라이언트의 작업 폴더(roots)와 변경 알림을 지원합니다.

**개선**

- 기존 원격 장부를 이어 쓰고, 같은 저장소의 worktree는 장부 하나를 공유합니다.
- 서로 다른 저장소에서 실행한 세션은 독립적으로 동작합니다.
- 원격 접근 실패를 빈 장부로 취급하지 않습니다.

roots 미지원 도구나 작업 대상이 모호한 경우에는 MCP 인수 `cwd`로 작업 폴더를 지정합니다.
커밋 검증이 필요한 저장소에는 `axmap hook install`을 실행합니다.

[릴리스 소스 →](https://github.com/rl2aderjoon/axmap/tree/v1.3.0)
